Frequently asked questions

The questions below are the ones the support team gets most often. For anything else, email support@toolbox.example.

What runtime versions do you support?

Toolbox runs on Bun 1.3 and later. Node 20+ also works in compatibility mode but some features (filesystem fast paths, native SQLite) are slower.

Can I self-host?

Yes. The community edition is MIT-licensed and runs on any Linux host with at least 2 GB of RAM and 8 GB of disk. See the self-hosting guide for details.

How do I migrate from v1 to v2?

Run toolbox migrate against your existing database. The command is idempotent and reversible. We recommend taking a backup first regardless.

Is there an API?

Yes — every operation in the dashboard is also available via the HTTP API at /api/v1/*. API tokens are generated in Settings → API.

What is the rate limit?

Free plan: 100 requests per minute. Pro and above: 1000 requests per minute, with bursts up to 5000.

How is data encrypted?

At rest, AES-256-GCM. In transit, TLS 1.3. Customer-managed keys are available on Enterprise.

Do you have a Slack app?

Yes. Install from the Slack App Directory; the workspace owner needs to authorise it. Once installed, slash commands are available in any channel.

Still stuck?

Check the changelog or open a discussion on GitHub. The support email is the fastest path for paid customers.
