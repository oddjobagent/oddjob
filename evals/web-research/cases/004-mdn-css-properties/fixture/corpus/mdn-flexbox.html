CSS Flexbox properties

The properties below are defined by the CSS Flexible Box Layout module (level 1). For each, MDN provides the property name, the values it accepts, and a short description.

Container properties

display
Set to flex or inline-flex to enable flexbox layout on a container.
flex-direction
Defines the main axis. Values: row | row-reverse | column | column-reverse.
flex-wrap
Whether items wrap to a new line when they overflow.
flex-flow
Shorthand for flex-direction + flex-wrap.
justify-content
Aligns items along the main axis.
align-items
Aligns items along the cross axis.
align-content
Aligns wrapped lines (only applies when there is wrapping).
gap
Shorthand for row-gap + column-gap.

Item properties

flex-grow
How much an item can grow relative to siblings.
flex-shrink
How much an item can shrink relative to siblings.
flex-basis
Initial size before grow/shrink.
flex
Shorthand for grow + shrink + basis.
order
Reorders items independent of source order.
align-self
Overrides align-items for a single item.

See also

Related — but NOT defined here — are the Grid properties: grid-template-columns, grid-area, and grid-gap. Do not include those.

The deprecated property box-flex from the old "flexible box" model is also out of scope for this page.
